# Selin AI — Autonomous AI Employee Platform
### 🚀 Проект для участия в конкурсе цифровых инноваций
---

## 📋 Описание проекта
**Selin AI** — это инновационная полнофункциональная платформа для создания и управления автономными цифровыми сотрудниками (AI Employees). Проект решает задачи автоматизации бизнеса, клиентского обслуживания, юридического сопровождения и планирования через интеллектуальных агентов, интегрированных в экосистемы корпоративных мессенджеров (Max Messenger, Telegram) и веб-интерфейсы.

## 🏛️ Слайд-Шоу: Структура Презентации

### Слайд 1: Selin AI — Автономный ИИ-Сотрудник Нового Поколения
* **Заголовок:** Платформа суверенных бизнес-агентов
* **Проблема:** Традиционные чат-боты ограничены простыми сценариями. Сотрудникам не хватает автономности, возможности выполнения финансовых транзакций, юридического анализа и реальной интеграции с внешними API.
* **Решение:** Selin AI — оркестратор специализированных ИИ-агентов с собственной базой данных (SQLite/Redis), системой безопасных финансовых расчетов (YooKassa/Robokassa) и бесшовной работой в мессенджере Max Messenger.

### Слайд 2: Технологический Стек Платформы
* **Frontend:** SPA на React + Vite + Tailwind CSS для удобной панели управления.
* **Backend:** Express.js сервер на Node.js (TypeScript) с компиляцией через esbuild для высочайшей производительности.
* **База данных:** sqlite3 (для локального кэша сессий и профилей) + Redis (высокопроизводительный кэш данных).
* **AI Core:** Интеграция с передовой библиотекой `@google/genai` (модели класса Gemini 2.5/1.5 Flash).
* **Спецификации:** Полная поддержка протокола Model Context Protocol (MCP SDK) для исполнения внешних инструментов в режиме реального времени.

### Слайд 3: Модуль Оркестрации Агентов (SelinCore)
* **Многоагентная архитектура:** Запросы пользователей распределяются между специализированными ролями (FinTech Агент, Агент Планирования, LegalScout юридический агент, Voice Агент).
* **Structured Outputs:** Все ответы ИИ-моделей валидируются схемами Zod на уровне бэкенда перед отправкой клиенту. Это гарантирует 100% точность формата ответов и исключает галлюцинации ИИ.
* **Safe Parsing:** Многоуровневые обработчики ошибок (Global Error Handlers) гарантируют отказоустойчивость всей системы.

### Слайд 4: Финансовый Модуль (FinTech Integration)
* **Подписки и Платежи:** Полноценный биллинг на базе ЮKassa и Robokassa. Автоматическое выставление счетов прямо внутри диалога.
* **Failover-механизмы:** Интеллектуальный планировщик подписок и система напоминаний контролируют статусы платежей.
* **Аварийная активация:** Специальные сценарии миграции балансов пользователей для бесперебойной работы.

### Слайд 5: Речевые Технологии (Voice Synthesis Core)
* **Качественный TTS:** Интеграция с современными движками синтеза речи для генерации озвучки ответов агента.
* **Стартовые крючки (Start Hooks):** Предварительная генерация аудио-приветствий на бэкенде для мгновенного отклика (нулевая задержка).
* **Нормализация текста:** Умный модуль озвучивания чисел, дат, валют и сложных библейских отсылок перед озвучкой.

### Слайд 6: Кибербезопасность и Безопасность ИИ (Security Layer)
* **Model Armor:** Защита от prompt-инъекций и вредоносных команд на входе.
* **Semantic Guard:** Фильтрация недопустимого и токсичного контента на выходе ИИ-модели.
* **Anomaly Detector:** Система выявления подозрительной активности пользователей и предотвращения DDoS/спам атак.
* **Circuit Breaker (Предохранитель):** Автоматическое переключение на резервные ИИ-модели или локальные сценарии в случае сбоя внешнего API Gemini.

## 📈 Преимущества для конкурса цифровых инноваций
1. **Продукт готов к эксплуатации (Production-Ready):** Это не прототип на коленке, а развернутая в облаке Docker-система с реальными платежами, логами и базами данных.
2. **Гибридный интерфейс:** Полноценный веб-интерфейс (React) + Мощный чат-бот (Max Messenger & Telegram), работающие синхронно.
3. **Безопасность корпоративного уровня:** Встроенная валидация схем, предохранители API и модули кибербезопасности.
4. **Социальная ценность:** Возможность адаптации под образовательные, бизнес и социальные проекты.
